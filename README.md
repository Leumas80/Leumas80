## 🌟 Featured Project

### 🧪 TM Executor — Test Execution & Integration Framework

**TM Executor (TME)** is a lightweight web-based solution designed to simplify the execution and monitoring of automated tests through **REST API integration with UiPath Test Manager**.

The project demonstrates how Test Manager capabilities can be integrated into a lightweight execution interface without requiring Orchestrator as the execution front end.

### Key Features

- ▶️ Execute **Test Cases and Test Sets** through a web interface.
- 📊 Monitor test execution status and telemetry.
- 🔗 Integrate with **UiPath Test Manager REST APIs**.
- 📡 Retrieve execution results through API integration.
- 📄 Process and generate test execution reports.
- 🔄 Use **Postman workflows** for API exploration and validation.
- 🐳 Support **Docker-based deployment**.
- 💻 Lightweight HTML/JavaScript frontend.
